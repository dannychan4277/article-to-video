# 只用財經圖表風格，文章的圖重畫、不貼

試跑的示範片裡，財經圖表（白底、紅黑白）和 Vox 剪報畫面（牛皮紙桌面、原圖貼上去、螢光筆加紅圈）交錯，看起來像兩支片剪在一起，風格不一致。Danny 決定：**每個分鏡都用財經圖表**，不再用 Vox。旁白講到作者文章裡的某張圖時，Claude 照圖上的數字重畫成財經圖表，來源行寫「來源：作者原文（圖N）」，不把原圖本身貼上畫面。

## 後果

- **圖上的數字要有出處**：作者的圖常有文字裡沒寫的數字（柱上的值、表格的格子）。數字對帳多一種出處「原文圖表」：Claude 看過圖N，把讀到的數字和「它在圖上是什麼」記在 `<專案>/article/figure_numbers.json`；畫面上對得到的數字標成「原文圖表（圖N，Claude 讀圖）」，審片頁那一區不收起來、標成要看一下，請作者對照自己的原圖。沒記下的數字照樣無出處、擋出片。讀圖是 Claude 讀的、程式驗不了，所以靠作者對照把關；讀不清楚的（沒標數值的線、糊掉的圖）規則要求不要估。重跑文章擷取會拿掉這個檔，圖換了要重讀。
- **畫面變化改靠圖型**：柱、折線、大數字、差距、接續分鏡換標註。少了剪報那種「這是原文」的質感，換來一致的畫面；要引用原句時把重點寫成標題或標註。
- **Vox 的程式留著、流程碰不到**：vox.py、boxes.py、excerpt.py、引擎 y2_vox 和它們的測試都還在（那是能用的程式，以後也許要回來）。分鏡設定裡有 `vox` 時，載入就擋下並說明「現在只用財經圖表、文章的圖要重畫」（舊專案打開來改也會碰到，Claude 照說明重畫）。只有環境變數 `ARTICLE_TO_VIDEO_INTERNAL_VOX=1` 打開時讀得到 Vox 分鏡——只給 Vox 自己的測試用（`tests/conftest.py` 的 `internal_vox`）。skill 不叫 `boxes`、`confirm-box`，也不預先核准它們；Vox 的規則搬到 `docs/vox/vox-rules.md`（停用中）。要重新開放就把開關拿掉、規則接回 skill，並重新想風格怎麼搭。
