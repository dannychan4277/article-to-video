# 內嵌引擎出處與修改紀錄

這個資料夾的動畫引擎來自 **huashu-art-motion**，作者是**花叔**（alchaincyf，<https://github.com/alchaincyf/huashu-art-motion>），以 MIT 授權釋出，授權原文保留在同資料夾的 `LICENSE`。感謝花叔把整套引擎開源。

外掛只帶「財經圖表」（`t3_finance_chart`）和「Vox 剪報」（`y2_vox`）兩種片段用得到的部分，另外帶了片段驗收工具（`qa.py`）。複製來源是 2026-10-06 發布包，加上 Danny 本機做第一支財經解說片時的修正（上游 CHANGELOG 2026-10-08 那一條）。

## 帶了什麼

| 檔案 | 用途 |
|---|---|
| `render.py`、`clip.html`、`clip.js` | 片段渲染：一份分鏡設定（JSON）→ 時長精確的片段或靜幀 |
| `clips/t3_finance_chart.js`、`clips/y2_vox.js` | 兩種片段的畫法 |
| `lib/{util,paint,kit,motion,camera,diagram,typo,chart,ui,collage,fonts}.js` | 兩種片段共用的函式庫 |
| `lib/fonts/` | 字型子集（SIL OFL 1.1，見 `lib/fonts/LICENSES.md`、`lib/fonts/OFL.txt`），不屬於 MIT |
| `qa.py` | 片段驗收（穩定、動感、框景） |
| `examples/t3_finance_chart.json` | 外掛自己寫的繁中財經圖表範例（數字取自 FRED 公開資料 DGS2） |
| `clips/a2v_end_card.js` | **外掛自己寫的**片尾卡語法（不是花叔原版）：頻道名、logo（兩樣都選填）、資料來源、免責與 AI 配音聲明，沿用引擎的字型與版式工具 |

沒帶的：其他語法與場景、示範片、參考影片、上游的範例資料、花叔的卡通形象與角色素材（`toon.js`、`rig_huashu.js` 等，上游明訂不隨 MIT），這兩種片段用不到的字型，以及外掛沒呼叫的兩支腳本：字幕帶圖形檢查 `scripts/subzone_gate.py`（外掛的 `auto_checks.py` 照它的做法另寫，改成任何畫面大小都能用）、程式作曲範本 `scripts/audio/synth_艺术史速通.py`（外掛的 `music.py` 照它的做法另寫，見最後一條）。

## 這個外掛另外做的修改（搜「article-to-video 內嵌」）

- `clip.html`：拿掉 `lib/toon.js`（花叔角色，兩種片段都用不到）。
- `lib/fonts.js`：只列外掛附帶的 5 個字型（clip.js 會逐一載入清單上的每個檔，少一個就開機失敗）。
- `lib/kit.js`：只留 `diagram.js` 用到的 `densify`、`resample`。
- `lib/fonts/LICENSES.md`：只列附帶的字型，補上原清單沒有的 Noto Sans CJK TC 子集。
- `clip.js`：缺字除了告警，也記在 `window.__missingGlyphs`。
- `render.py`、`qa.py`（照上游 57d6760，2026-10-08）：本機伺服器改多執行緒——`LocalServer(socketserver.ThreadingTCPServer)`，
  `request_queue_size = 128`、`daemon_threads = True`（只用子類別，不改標準庫類別的全域屬性），收尾 `shutdown()` 後加 `server_close()`。
  Chromium 並行載入腳本時可能先開好閒置連線，單執行緒的伺服器會卡在那條連線上、其他檔案載不到（上游在 Windows 上遇到；
  Apple Silicon macOS 上量不到差別，是防呆）。測試：`tests/test_engine_server.py`（不開瀏覽器，只連 127.0.0.1）。
  **外掛另加（上游沒有）**：處理器 `Q.copyfile` 檔案內容一次只送一個（類別上一把鎖；請求、閒置連線照樣各自一條執行緒），
  `send` 回 ENOBUFS／EAGAIN 時等 0.01 秒再送剩下的（最多 30 秒）。原因：多執行緒後 Chromium 同時要三個 7 MB 多的字型，
  macOS 機器很忙時網路緩衝區不夠，字型檔沒送完、片段報「字型缺字」失敗——同時渲 8 個、6 輪：照上游原樣 48 次失敗 5 次
  （`OSError: [Errno 55] No buffer space available`），單執行緒 0 次；加了這兩樣之後 8×10、12×6 都 0 次。
- `render.py`：spec 用 UTF-8 讀；`--ffmpeg <路徑>` 指定 ffmpeg（不靠 PATH）；檢查 ffmpeg 結束碼；`--strict-glyphs` 有缺字就在渲染前失敗；頁面 `console.error` 印成 `[page-error]`，跟告警 `[page]` 分開。
- `qa.py`（圖表鏡頭快推）：`--spec` 片段模式在 `qa.json` 每段多記 `ts`（每一幀的時刻）與 `pair_diffs`（相鄰兩幀變動的畫面 %），
  外掛的 `auto_checks.py` 照 spec 裡已知的快推時段拿掉那幾個幀對、用同一套門檻重算跳變。qa 自己的判讀（`spikes_at_lt` 等）不變。
- `qa.py`：`--project` 預設是本資料夾（qa.py 跟引擎放在一起）；spec、`qa.json`、`qa.md` 用 UTF-8 讀寫。四幀拼圖的頁首改用外掛附帶的繁中字型（`lib/fonts/NotoSansTC-500.woff`）、寫繁中（動態、靜止幀對、跳變、確定性），頁首高 20 → 26 px（原版用 PIL 預設字型，使用者的 Mac 上中文全是豆腐字）。
- `clips/t3_finance_chart.js`：`data.colors.brand` 品牌色，取代「當品牌用的紅」（頂端色條、小旗、角標、標註圓點、大數字、折線預設色）；沒寫就是原本的紅 `#E3120B`。折線下方漸層改跟著線的顏色（原本寫死紅色）。K 線漲跌的紅綠不變。
- `clips/t3_finance_chart.js`：`data.colors.ink`：要讀的字與記號（角標、標註圓點、大數字）用的顏色，沒寫就跟 brand 一樣——品牌色太淺時外掛的 `brand.py` 給它同色相加深的版本，色條、小旗照用原色。
