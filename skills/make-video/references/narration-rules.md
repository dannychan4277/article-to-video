# 旁白規則

旁白是作者的觀點、用 AI 配音唸出來、底下燒成字幕。寫的時候同時想三件事：聽得懂、像作者會講的話、每一小句對得到一個畫面。

## 內容：只講文章講的

- **用作者的詞**。文章裡的專有名詞、自創說法、關鍵句照抄，不要換成同義詞（作者寫「期限溢價」就不要寫「風險補償」）。
  文章的口氣是斷言就斷言，是推測就保留推測。
- **不加文章沒有的主張**。不補充背景知識、不加預測、不加「這代表你該怎麼投資」。文章沒寫的因果、比較、數字，一律不寫。
- **限定詞要留著**：暫時、約、可能、某一類、作者認為。口語化最常犯的錯是把這些拿掉，講得比原文重。
- **數字以文章為準**：文章寫幾就唸幾，精度不超過文章（文章寫「約 4.6%」就唸「約四點六」）。
  推算出來的數字（差值、倍數）可以講，但畫面上要放、分鏡要宣告算式（`formats.md` 的 `derived`）。
- 文章的觀點不是事實時，要讓觀眾聽得出是作者的看法（「我認為」「我的判斷是」，照作者第一人稱的寫法）。

## 長度與開場

- **全長 2–4 分鐘**：約 530–1050 字（`lint` 用每秒 4.4 字估）。真正的長度看 `narrate`／`preview` 印的「總長」。
  太長就只留主線（一篇文章通常只有一個主結論和兩三個支撐證據），太短就把證據講完整。
- **第一秒就是重點**：第一句直接講文章最重要的結論或最讓人意外的數字，沒有片頭、沒有寒暄。
  不要「大家好」「今天要來聊」「你有沒有想過」（`lint` 會擋）。

## 寫法（`lint` 會查，跑到「要改 0 項」為止）

| 規則 | 門檻 |
|---|---|
| 每段字數 | 25–60 字（約 6–15 秒）。一段＝一個小主題 |
| 一口氣 | 用「，。？！；」切開的每一塊 ≤ 12 字（字幕一行、配音一口氣） |
| 一句 | 用「。？！」切開的每一句 ≤ 25 字 |
| 數字寫成唸法 | 不寫阿拉伯數字和 %：「四點五八」「百分之五」「零點六二個百分點」「兩千零二十三年」或「二零二三年」 |
| 套話 | 賦能、打造、助力、全方位、深度、閉環、抓手、值得注意的是、總的來說、綜上所述、不僅 |
| 開場 | 第一段不寒暄（見上） |

「看一下」的提醒（模糊量詞、虛動詞、雙重否定、指代、英文縮寫、全長）不擋，但大多值得改：
「一些」換成數字、「進行調整」寫「調整」、「它」講不清楚就重複名詞、英文縮寫（FRED）唸起來怪就改中文（聯準會的資料）。

- 年份不要寫「〇」（字幕字型沒有這個字）：寫「二零二三年」，或乾脆說「去年」「前年」——只在文章本身這樣寫時。
- 每段最後一句要能單獨成立：觀眾可能從這裡開始聽。

## 跟分鏡一起想

- **每個逗號塊配一個畫面事件**：一塊講兩年期（長出第一根柱）、下一塊講十年期（第二根柱）、再下一塊講結論（標註）。
  寫旁白時就想好每一塊要配什麼畫面，分鏡的錨點才找得到詞。
- **錨點詞在那一段裡唯一**：要拿來對畫面的詞（數字、名詞）在同一段不要出現兩次，不然要加 `occurrence`。
- 列舉（第一、第二、第三）每一項都要有自己的畫面，序數詞就是切入點。
- 唸到哪個數字，那一刻畫面上就要有那個數字（柱上的數字、標註或大數字）。
- 直式片的字幕一行約 17 字，「一口氣 ≤ 12 字」已經夠短。

## 改旁白（作者在審片頁說「旁白改成…」）

- 只改他指的那幾段（`feedback` 會列出那個分鏡唸的旁白段）。其他段一個字都不要動：沒改的段不用重新配音。
- 改完跑 `lint`；被錨點用到的詞改掉了要一起改分鏡的錨點。
