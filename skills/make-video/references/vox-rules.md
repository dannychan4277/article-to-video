# Vox 分鏡規則（文章原圖、原文剪報、框）

主 skill 做 Vox 分鏡時照這份做。這些規則來自殖利率那支片的三輪審片；能自動檢查的，程式會擋或提醒（標「程式會擋」「程式會提醒」），其他的要你自己看靜態圖確認。

## 什麼時候用 Vox 分鏡

- 旁白講到作者文章裡的某張圖、或要引用文章原句當證據時，切到 Vox 桌面：把原圖（圖N）或原文剪報貼上去，框出旁白正在唸的那個數字。
- 講數字走勢、比較，用財經圖表；兩種分鏡可以在同一支片裡交錯。
- 只能用作者自己文章裡的圖和文字（`article/article.json` 列出的圖N 與段落），不能用網路上找的圖。

## shots.json 寫法

```json
{"id": "SH05", "start": {"segment": "s05"},
 "vox": {"cues": [
   {"at": 0, "kind": "image", "image": "圖2", "caption": "十年期殖利率"},
   {"at": {"segment": "s05", "word": "三點九六"}, "kind": "box", "rect": [714, 343, 100, 46]}
 ]}},
{"id": "SH06", "start": {"segment": "s06"}, "continues": true,
 "vox": {"cues": [
   {"at": {"segment": "s06", "word": "原文"}, "kind": "excerpt", "quote": "差距只剩"},
   {"at": {"segment": "s06", "word": "零點六二"}, "kind": "box", "find": "0.62"},
   {"at": {"segment": "s06", "word": "換句話說"}, "kind": "point", "text": "差距 0.62 個百分點"}
 ]}}
```

- `image`：文章原圖，寫編號「圖N」。圖下方自動有黑底標籤「圖N」；`caption` 會接在後面（「圖2｜十年期殖利率」）。
- `excerpt`：原文剪報。`quote` 寫要剪的那句裡的幾個字（照原文一字不差），會自動剪到整句；沒寫 `quote` 就整段（`paragraph` 指定第幾段）。標籤「原文段落」。
- `box`：框（螢光筆掃過＋紅筆圈＋鏡頭推近）。框原圖寫 `rect`（原圖的像素 [x, y, 寬, 高]）；框剪報寫 `find`（剪報裡要框的那幾個字），位置程式自己算。
- `title`：黑底白字標題條；`point`：橫線索引卡。卡上的數字跟圖表一樣要對帳。
- `at`：數字＝從這個分鏡開始算的秒數（不能是負的）；或錨點。**框一定要錨在旁白唸到那個數字的詞上**（程式會擋）。
- cue 照出場順序寫（程式會擋：寫在後面的比前面的早出現）。
- `"continues": true`：接續上一個 Vox 分鏡，同一張桌面、不切，鏡頭沿紅線走到下一件。上一個不是 Vox 分鏡不能接續（程式會擋）。

## 剪報

- **剪到句號**：剪報以整句為單位，結尾是「。！？」或段尾。程式會自動把引文擴到整句；跟這句擠在同一行的前後句殘字會遮掉。
- 一張剪報最多 6 行（程式會擋）：只剪要指給觀眾看的那一兩句。
- 剪報裡如果有旁白沒解釋的術語，觀眾會多一個問號：換一句，或用索引卡補一句解釋。

## 框（每個框出片前都要你看過）

1. 跑 `preview` 或 `boxes <專案>`：每個框會出兩張圖，在 `build/16x9/boxes/`：
   - `<分鏡>-框<n>-畫面.png`：框畫好、鏡頭推近之後，觀眾看到的那一刻。
   - `<分鏡>-框<n>-原圖.png`：原圖（或剪報）加 10% 格線與像素座標，紅框是 `rect` 的位置。改 `rect` 時對著格線讀座標。
2. 打開每一張「畫面」圖確認：
   - **螢光筆和紅圈剛好在旁白唸到的那個數字上**：只框那一個數字（一格、一個數），不要同時圈到兩個數字、相鄰那一列、別的日期，也不要壓到欄位名稱。框太大就縮。
   - 目標旁邊有容易看錯的數字（別的日期、別的欄位）時，改框得更緊，或改用索引卡把數字寫出來。
   - **螢光筆不能刷到圖例色塊**：螢光筆只上在紙上，字和色塊保持原色（藍字還是藍、紅字還是紅），所以刷到色塊上看不出黃，紅圈又像在圈圖例，觀眾會看錯在指哪一條線。框要從色塊右邊的字開始（留幾個像素），或改框圖裡對應的那根柱子／那個點（框到大塊彩色時程式會提醒）。
   - 數字沒被畫面邊緣切到，也沒掉進底部字幕帶。
   - 原圖本身的數字是完整的（原圖右緣被截掉的數字不能框）。
3. 都沒問題才核對：`confirm-box <專案> SH05:1@xxxxxxxx …`（代號在 `boxes` 的輸出裡）。只寫你真的看過的框。
4. 框、原圖、剪報、錨點的詞、那句旁白任何一樣改了，那個框就要重看、重新核對；**沒核對過的框會擋正式出片**（預覽不擋）。

## 時間

- **框和下一件素材至少隔 2 秒**（程式會擋）：框出現後鏡頭要推近、停住讓觀眾看清楚；太快換下一張圖、剪報、文字卡或切到下一個分鏡，推近只停一下就甩走。不夠就把下一件的錨點往後挪、框的錨點往前挪，或把那句旁白寫長一點。
- 同一張圖要框兩個數字（例如對比「先刷 A、再圈 B」）時，兩個框都要錨在各自的數字上；兩個框之間建議隔 1.5 秒以上。
- 一句旁白一個畫面事件：圖貼上去之後，下一句就該有框或新的素材；鏡頭停在同一張圖上會慢慢推近（停留慢漂），但慢漂不能代替新資訊，停太久（約 5 秒以上沒新東西）觀眾會覺得卡住。
- 放大有上限：原圖解析度不夠時，框得太小會被推得很近而變糊。框寬至少約原圖寬的十分之一；原圖太小就請作者給清楚一點的圖（PDF 原檔、Word 檔）。
