# 分鏡規則

這些規則來自一支 3 分鐘財經解說片的三輪獨立審片（分數 6 → 8.5）：每一條都是觀眾真的看錯、看不懂、覺得卡的地方。
標「程式會擋」「程式會提醒」的有自動檢查；其他的要你看分鏡靜態圖自己確認。
**每個分鏡都是財經圖表（`chart`）**：整支片一種風格。講到作者文章裡的圖，也是照圖上的數字重畫成財經圖表（見「文章裡的圖」）。
寫分鏡之前先配音（`narrate`）：它印每段的起點、長度和每個詞開始唸的秒數，下面講到的「幾秒」都拿它算。

## 節奏：一句一張圖

- **一句旁白（或一個逗號塊）一張圖、一張圖只講一件事。** 預設每一句開一個分鏡；同一張圖要換標註、或下一根柱這一句才長，
  用接續分鏡（`"continues": true`），第一幀就是畫好的樣子，切點看不出來，鏡頭也接得上（慢推接著推；快推從上一下停住的地方接著）。
  一張柱狀圖講好幾句（「二零二二年……二零二三年最深……到二零二五年」）：**一句一個接續分鏡**，每句寫那一句的
  `bar`（帶 `data.index`）或 `highlight`，不要把整串柱都塞在一個二十幾秒的長分鏡裡（後面幾句的標註會換不到、強調停在舊的那根）。
- **畫面在旁白講到那個詞時才出現。** 柱、線、標註、大數字一律用錨點對上旁白的詞，不寫死秒數（只有 `title` 可以 `"at": 0`）。
  任何資料比旁白早 1 秒以上出現，觀眾會把它讀成上一句在講的東西。
- **數字的 `at` 寫在唸到它的那個詞的開頭，落定後停 1.5 秒以上**（大數字卡、圖上的大數字、兩數對比的數字和差距；細節見 formats.md）：
  寫在唸完、或下一個分鏡緊跟著切，數字只在畫面上停零點幾秒，觀眾看到的是滾到一半的數（計時實測兩項必修）。停不到 1.5 秒 `preview` 會印「提醒：」，照著改。
- **只講概念、沒有數字的句子，不要配一張不相干的數據圖**（例「正常的殖利率曲線往右上斜」配逐年的利差柱）：觀眾會把概念套到
  畫面上正在長的東西，把「期限」讀成「時間」（計時實測必修）。引擎畫不出示意圖，照這個順序處理：
  1. 回頭改旁白（最好）：把概念講成文章裡有數字的事實（「X 年，十年期比兩年期高 Y 個百分點」），就有柱、有數字可以出來（narration-rules.md「每一句都要有東西可畫」）。
  2. 沿用上一張圖：開接續分鏡，用標註的字把概念寫在圖上相關的那一點（例標在一根正的柱上：「正常：長天期比較高」）。
  3. 前後都沒有合適的圖：這句不另開分鏡，讓上一個分鏡多停這一句（不超過約 5 秒），下一個分鏡從有數字的那個詞切入。
  不要為了「畫面有東西在動」畫旁白沒講到的數字。
- **結論式標題等旁白講到結論那句再出現**：旁白還在鋪陳時，標題先放中性的描述，或拆成兩個分鏡。
- **每一句至少一個新畫面事件**（新柱、新的線、新標註、新的大數字、兩數對比的數字或差距）；超過約 5 秒沒有新東西就算卡（程式會提醒「停太久」）。
  慢推、慢漂不能代替新資訊。換圖後第一個資料 0.5 秒內就要開始出現。
  圖表鏡頭預設是快推（`camera: snap`，見 formats.md）：畫面平常是停住的，只在新標註出現時推一下：
  一句旁白配一個新標註（同一張圖就開接續分鏡換標註），畫面才不會停太久；要強調的那一刻就寫成標註，不要只用大數字。
- **「停太久」要補畫面事件，不要把資料提早。** 自動檢查說某一段停太久時，最常見的錯是把後面那根柱、那個數字提早長出來——
  那就變成「資料比旁白早」（計時實測：為了補 5 秒空檔把柱提早，被審片判早 2.3 秒）。照這個順序補：
  1. 那段旁白裡有詞對得到圖上的東西：在那個詞長那根柱（帶 index 的 `bar`）或換標註。
  2. 沒有新數字：開接續分鏡，在這段的關鍵詞換標註的字。同一點只換字也算一個畫面事件（例「倒掛最深的一年」→「轉正靠的是哪一端？」）。
  3. 還是沒有：那段旁白太長或在繞，改短（改旁白要重新配音）。
- **列舉幾件事，每一件都要有畫面**，跟「第一、第二、第三」對齊（每一件一個短分鏡，從序數詞切入）。
- **唸到誰就點亮誰**：旁白講 B 的數值時，標註要在 B 上，不是 A；而且旁白**一開口講到 B** 就換過去，不要等這句唸完（見下面「標註跟著旁白」）。
- **開場第一幀就是重點**：第一個分鏡從 0 秒開始，標題就是文章的主結論或最關鍵的數字，沒有片頭。

## 圖表版面要有變化

整支片都是財經圖表（同一套版式），變化靠**圖表版面**：柱狀、折線、K 線、大數字卡、兩數對比（欄位見 formats.md）。
審片抓過的「單調」就是整支片幾乎都是同一種柱、線版面。

| 要講的事 | 用什麼 |
|---|---|
| 比較三到八個數（幾個天期、幾家機構、幾年） | 柱狀（`bar`），跟著旁白一根一根長出來 |
| 兩三個數，重點是「差一半」「翻倍」這種比例 | 柱狀：兩三根柱會自動變寬、靠在圖區中間，高低一眼看得出來 |
| 走勢（一段時間怎麼變） | 折線（`line`）：公有數據（`publicData`），或文章的圖上有標的點 |
| 這一句就在講**一個**數字（「連續倒掛七百八十二天」），而且不是往下跌的數 | **大數字卡**（`"chart": "number"`）：整個畫面就是那個數 |
| 一張圖的旁邊順便帶一個摘要數字 | 圖上的大數字（`number` cue，右上角） |
| 旁白唸出**兩個**數字來比（「從負零點六二走到零點四八」「兩年期四點五八、十年期三點九六」），要看的是確切的數 | **兩數對比**（`"chart": "compare"`）。講「差多少」就加差距（`gap`），講「哪一個高／低」就強調（`highlight`） |
| 「從多少跌到多少」 | 兩數對比（不要用大數字卡：它從 0 往上滾，跟「跌」打架） |
| 同一張圖講好幾句 | 接續分鏡，每一句換一個標註（兩數對比是換強調、補差距） |
| 股價、指數的開高低收 | K 線（`candle`），只在文章裡有那幾個數字時 |

怎麼排（避免連續好幾鏡同一種版面）：
- **同一種版面不要連續超過三個分鏡**（接續分鏡算同一張）。例：大數字卡 → 折線 → 柱 → 兩數對比 → 柱 → 折線，比五張柱好。
- **大數字卡、兩數對比各自不要連著兩個**：第二個數字改用兩數對比、柱，或放進圖裡（右上角大數字、標註）。
  大數字卡和兩數對比也不要連著用（兩張都是「只有數字」的畫面）。
- **大數字卡少用、用在刀口上**：開場的鉤子數字、全片的關鍵結論。3 分鐘的片 1～2 張就好；用多了就不特別了。
  它只有一個畫面事件（數字落定），分鏡要短（一句、約 5 秒內），不然會被提醒「停太久」；後面還有話就切到圖。
- **兩數對比 1～3 張**：比一般的柱更「正式」，適合全片的關鍵比較。兩個數字的單位要一樣（都是 %、都是天）；
  單位不一樣的兩個數不要並排（會被讀成可以直接比）。
- 文章裡有一張好幾根柱的圖，旁白只講其中兩個數：照原圖重畫成柱（觀眾會跟原圖對），不要硬改成兩數對比。
- 一張圖的資料點別太多：柱狀 ≤ 8 根比較讀得清楚（超過 14 根柱上不寫數字）。

## 文章裡的圖：重畫成財經圖表

旁白講到作者文章的某張圖（圖N）時，**不貼原圖**，照圖上的數字重畫成財經圖表——跟整支片同一種風格。

1. **數字從哪來**：文章文字裡有的數字直接用；只畫在圖上的數字，照 SKILL.md 第 2 步讀圖、記進 `article/figure_numbers.json`
   （格式見 formats.md「讀圖記下的數字」）。數字對帳會把它們標成「原文圖表（圖N，Claude 讀圖）」，審片頁請作者對照原圖。
   沒記的數字對不到出處，會擋出片。
2. **來源行**寫 `"source": "來源：作者原文（圖N）"`（片尾卡會把幾張圖併成「作者原文（圖1、圖3）」）。
   原圖自己標了原始出處（例「資料：聯準會」），接在後面：`"來源：作者原文（圖2）；原始資料：聯準會"`
   （片尾卡把它們分成兩個出處，各自跟別張圖的同一個出處併成一行）。
3. **圖型照原圖的意思挑**：
   - 柱狀圖、表格的一列或一欄 → 柱狀；只挑旁白講到的那幾個，順序跟原圖一樣。
   - 走勢線 → 折線，只用圖上有標數值的點。**沒標數值的線不要估**：那條線是白名單公有數據（十年期、兩年期殖利率…）就用
     `publicData` 重抓（來源會寫 FRED，不是作者原文）；不是就只畫圖上有標的那幾點，或用文章文字裡的數字。
   - 一個關鍵數字 → 大數字。
   - 圓餅、占比 → 柱狀（%）。引擎沒有圓餅。
   - 好幾條線的圖 → 一個分鏡畫一條，或挑關鍵時點畫成並排的柱。
4. **照原圖的寫法**：類目名、年份、單位、系列名稱跟原圖一樣，數字的精度也一樣（原圖寫 4.5 就不要寫 4.50）——作者對照時才認得出來。
   標題照樣寫這張圖要說的結論（不是「圖2」）。
5. **一張圖講好幾句**：第一個分鏡畫圖，後面用接續分鏡換標註或長下一根柱（bar cue 寫在那一句的接續分鏡），一句一個重點。
6. 要引用原文某一句當證據：把那句的重點寫成標題或標註（數字照原文），不要把整段文字搬上畫面。

## 標註跟著旁白

計時實測：第 1 輪獨立審片 5 項必修全是「標註比旁白晚」——標註照舊文件錨在數字唸完（`edge: end`）或句尾，新的一句已經在講別的，
畫面還停在上一句的標註（聽到「多了」、看到「少了」），晚 1～4 秒。改成錨在那句主詞的開頭就全修好了。

1. **錨點放在這句開始講它的那個詞**：被標的那一點的主詞、時間點，或帶出數字的那幾個字（「十年期」「二零二三年」「相差零點六二」）。
   `edge` 用預設的 `start`，不要寫 `end`，不要錨在句尾的結論詞。
2. **在旁白唸到標註上的數字之前就要長好**：換一次標註（舊的淡出、柱淡掉、新字長出來）要 0.5 秒才看得清楚，完整換完約 1 秒。
   最晚錨在數字那個詞的開頭（唸數字的時候剛長好）；數字就在句首（「二零二三年，……」）就錨在句首。
3. **那根柱這一句才長**：柱先長（錨在主詞），標註錨在柱後面那個詞（柱長完、數字唸到之前），例：

   ```json
   {"id": "SH02", "start": {"segment": "s01", "word": "十年期"}, "continues": true,
    "chart": {"data": {"highlight": {"index": 1, "text": "長天期較低"}},
              "cues": [{"at": {"segment": "s01", "word": "十年期"}, "kind": "bar", "data": {"index": 1}},
                       {"at": {"segment": "s01", "word": "只有"}, "kind": "highlight"}]}}
   ```
   （旁白「十年期只有三點九六，曲線倒掛。」：唸到「十年期」柱開始長，唸到「只有」標註換過來，唸到「三點九六」時已經長好。
   舊寫法 `{"segment": "s01", "word": "倒掛", "edge": "end"}` 要等整句唸完，「三點九六」唸的時候畫面上還是上一個標註。）
4. **標註至少停 1.5 秒才換**（換下一個標註，或切到別張圖）：前 0.5 秒在長，看得清楚的時間才有 1 秒。兩個主角在 1.5 秒內接連出現
   （「七成來自 A，三成來自 B」唸得很快）：寫一個兩行的標註一起講，或讓第一個早一點出來；標註出現沒多久就切走的，
   把下一個分鏡的切入點往後放，或標註再提早。
5. **跟「停太久」一起算秒數**：標註從句尾提早到句首，它後面那一段就多出一兩秒沒有新東西。改完用 `narrate` 印的秒數算一次：
   這個標註到下一個畫面事件（下一個標註、下一根柱、下一個分鏡）超過約 5 秒，就在中間補一個事件（照「節奏」那一節的順序：
   有詞對得到圖上的東西就長柱、換標註，沒有就把那段旁白改短），不要為了補空檔把資料提早。
6. **同一點只加第二行（`sub`）會閃一下**：引擎把整個標註淡出再長出來（審片判該修）。要補一句說明就換一句新的第一行，
   或一開始就兩行一起寫（formats.md「接續分鏡」）。
7. **大數字**：`at` 錨在引出數字的那個詞（緊接在數字前面的那幾個字），或數字那個詞的開頭——落定不要早於旁白唸到它 1 秒，
   也不要晚（寫在唸完）。錨在鋪陳的開頭，數字早就數完、卡片空等，審片會挑。

`preview` 會印「提醒：」：標註、大數字、差距、兩數對比的強調上的數字比旁白晚（唸到之後 0.5 秒還沒看得清楚）、會滾的大數字
比旁白早 1 秒以上落定、標註停不到 1.5 秒、同一點只改第二行。照它建議的錨點改（`{"segment": …, "word": …}` 照抄就能用）；
`checks` 也會把它們列成該修。**標註上沒有數字時程式比不出晚**（例「長天期較低」）：照第 1 條自己對——
看 `narrate` 印的秒數，標註的錨點要在這一句講到那一點的第一個詞。

## 標註與數字

- **標註寫「意思」，不重複數值**：柱上已經寫 4.58%，標註寫「短天期較高」而不是「4.58%」。
  大數字和柱上的數字也不要重複；要強調某根柱的數字，用 `series[i].text` 把柱上的字改成說明。
- **差值一定帶單位**：百分比之差寫「個百分點」或「基點」（「高 0.62 個百分點」，不是「高 0.62」）。兩數對比的差距（`gap`）
  單位寫在 `data.suffix`，不寫會擋；寫 `%` 也會擋（百分比相減是「個百分點」）。
- **畫面上每個數字都要有出處**：文章文字裡的數字、讀圖記下的數字（原文圖表）、公有數據，或宣告算式的推算（程式會擋：數字對帳）。
  數字寫成跟文章一樣的精度；文章寫「約」就在標籤或副標寫「約」。
- 文章是定性說法（「超過一半」）時，柱上寫 `"text": "＞50%"`，不要畫成剛好 50；需要的話 `badge` 寫「示意」。
- 作者自己的推估、換算，類目名寫清楚（「（作者推估）」），來源行分開「機構數字」和「作者推估」。
- 畫面上的年份寫阿拉伯數字（2023），不要寫「〇」（字型沒有，程式會擋）。

## 軸與圖型

- **柱一律從 0 起**（引擎自動）。**折線不從 0 起時圖上要寫明**：引擎會在副標後面自動加「縱軸未從 0 開始」，不要用 `axisNote` 把它拿掉。
- **下跌的數字不要用從 0 往上數的大數字**（`number` 會從 0 滾上去，跟「跌到」打架；大數字卡也一樣）：改用兩數對比（從多少到多少）、柱或標註。
  柱上的數字也是長的時候從 0 往上數；一根一根長的柱，**比左邊那根低**的（「降到三點八一」）程式會讓它的數字不滾、長出來就寫最後的數
  （負數柱反過來：比左邊高的不滾）。柱子本身還是從 0 往上長，所以要觀眾讀「從多少降到多少」這個變化時，用兩數對比（數字不滾、不長），
  或在柱上標註寫變化（「少了 0.77 個百分點」）。
- **機率、占比圖的縱軸寫死 `"yRange": [0, 100]`**：不寫的話，標註會在頭頂多留空間，縱軸會被推到 100% 以上。
  寫死之後標註擠的話，改用柱的顏色強調（`series[i].color`，寫了顏色的柱不會被標註淡掉），或另開一個分鏡。
- **縱軸被撐得太開**（線擠在圖的一小截、上面一大片空白）：先看標註是不是太長（改短），再不行就寫 `yRange` 把範圍寫死。
- **差異太小改畫差距**：幾個很接近的數（例如 102 和 105）畫成柱看起來一樣高。改畫「跟基準的差」（柱從 0 起），
  或用不從 0 起的折線並讓圖上寫明。
- 大數字（`number`）只放這張圖的指標；別的指標另開分鏡（大數字卡）。一個分鏡只放一個大數字。
- 「警戒線」「門檻」：引擎畫不出水平參考線，標題和旁白不要說「線」，改說「門檻」「情境」。
- 折線的時間軸：`xTicks` 放在每月或每年的第一個點，名字不要重複；最後一點的名字不要只寫年份。月資料一年 12 點時最後兩個名字會擠，用 `xTicks` 挑。
- 副標要描述「所有」柱子（只有部分是公式算的，就不要整條副標寫公式）；柱子的順序跟標題提到的順序一致。
- 指數類數據（標普五百等）**只能用文章裡寫的數字或文章的圖上讀到的數字**，不能自己抓（版權）。

## 看靜態圖時的檢查清單

`preview` 會印每個分鏡完成狀態那張靜態圖的路徑（`build/16x9/stills/<片段>/` 裡還有每個畫面事件前一刻的圖）。逐張用 Read 看：

1. 這一張講的事跟那句旁白一樣嗎？旁白唸到的數字在畫面上嗎？
2. 標題是一句結論、兩行以內；字沒有被切掉、沒有疊在一起、沒有掉進底部字幕帶。
3. 標註寫意思、沒重複數值；差值有單位；標籤、引線沒有壓在線或格線上。
4. 柱從 0 起；折線不從 0 起的有寫明；機率圖沒有超過 100%。
5. 下跌的數字沒有用往上滾的大數字；「從多少降到多少」用兩數對比或標註寫變化。大數字卡唸到數字時已經落定（`at` 寫在詞的開頭）。
   每個標註的錨點在那句開始講它的詞（不是句尾、不是數字唸完）；`preview` 印的「提醒：」都改掉了。
   只講概念的那一句，畫面上沒有放旁白沒講的數據。
6. 跟前後分鏡比：版面有變化（同一種不連續超過三個、大數字卡和兩數對比不連著用）；接續分鏡的版式和刻度跟上一張一樣。
   大數字卡、兩數對比：數字夠大、說明一行讀得完；強調的是旁白正在講的那一個；差距有單位。
7. 重畫文章的圖：跟原圖（`article/images/圖N.*`）並排看，數字、類目名、順序、單位都一樣；來源行寫了「作者原文（圖N）」。

有問題就改 shots.json 再 `preview`，只有改到的分鏡會重渲。
