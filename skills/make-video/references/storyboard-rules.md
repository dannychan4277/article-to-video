# 分鏡規則

這些規則來自一支 3 分鐘財經解說片的三輪獨立審片（分數 6 → 8.5）：每一條都是觀眾真的看錯、看不懂、覺得卡的地方。
標「程式會擋」「程式會提醒」的有自動檢查；其他的要你看分鏡靜態圖自己確認。
**每個分鏡都是財經圖表（`chart`）**：整支片一種風格。講到作者文章裡的圖，也是照圖上的數字重畫成財經圖表（見「文章裡的圖」）。
寫分鏡之前先配音（`narrate`）：它印每段的起點、長度和每個詞開始唸的秒數，下面講到的「幾秒」都拿它算。

## 節奏：一句一張圖

- **一句旁白（或一個逗號塊）一張圖、一張圖只講一件事。** 預設每一句開一個分鏡；同一張圖要換標註，用接續分鏡（`"continues": true`），
  第一幀就是畫好的樣子，切點看不出來，鏡頭也接得上（慢推接著推；快推從上一下停住的地方接著）。
- **畫面在旁白講到那個詞時才出現。** 柱、線、標註、大數字一律用錨點對上旁白的詞，不寫死秒數（只有 `title` 可以 `"at": 0`）。
  任何資料比旁白早 1 秒以上出現，觀眾會把它讀成上一句在講的東西。
- **結論式標題等旁白講到結論那句再出現**：旁白還在鋪陳時，標題先放中性的描述，或拆成兩個分鏡。
- **每一句至少一個新畫面事件**（新柱、新的線、新標註、新的大數字）；超過約 5 秒沒有新東西就算卡（程式會提醒「停太久」）。
  慢推、慢漂不能代替新資訊。換圖後第一個資料 0.5 秒內就要開始出現。
  圖表鏡頭預設是快推（`camera: snap`，見 formats.md）：畫面平常是停住的，只在新標註出現時推一下：
  一句旁白配一個新標註（同一張圖就開接續分鏡換標註），畫面才不會停太久；要強調的那一刻就寫成標註，不要只用大數字。
- **列舉幾件事，每一件都要有畫面**，跟「第一、第二、第三」對齊（每一件一個短分鏡，從序數詞切入）。
- **唸到誰就點亮誰**：旁白講 B 的數值時，標註要在 B 上，不是 A。
- **開場第一幀就是重點**：第一個分鏡從 0 秒開始，標題就是文章的主結論或最關鍵的數字，沒有片頭。

## 圖表類型要有變化

整支片都是財經圖表，變化靠圖型和畫法：

| 要講的事 | 用什麼 |
|---|---|
| 比較幾個數（兩個天期、幾家機構、幾年） | 柱狀（`bar`），跟著旁白一根一根長出來 |
| 走勢（一段時間怎麼變） | 折線（`line`）：公有數據（`publicData`），或文章的圖上有標的點 |
| 一個關鍵數字（「差了 0.62 個百分點」） | 大數字（`number`），配一張圖講它是什麼 |
| 兩個數的差距、跟基準比 | 差距柱（畫「跟基準的差」，柱從 0 起），或並排兩根柱＋標註寫差多少 |
| 同一張圖講好幾句 | 接續分鏡，每一句換一個標註（指到旁白正在講的那一根、那一點） |
| 股價、指數的開高低收 | K 線（`candle`），只在文章裡有那幾個數字時 |

- 同一種圖型不要連續超過三個分鏡（接續分鏡算同一張），不然看起來像模板，平台也可能判成模板化內容。
  例：柱 → 柱 → 折線 → 大數字＋柱 → 折線，比五張柱好。
- 一張圖的資料點別太多：柱狀 ≤ 8 根比較讀得清楚（超過 14 根柱上不寫數字）。

## 文章裡的圖：重畫成財經圖表

旁白講到作者文章的某張圖（圖N）時，**不貼原圖**，照圖上的數字重畫成財經圖表——跟整支片同一種風格。

1. **數字從哪來**：文章文字裡有的數字直接用；只畫在圖上的數字，照 SKILL.md 第 2 步讀圖、記進 `article/figure_numbers.json`
   （格式見 formats.md「讀圖記下的數字」）。數字對帳會把它們標成「原文圖表（圖N，Claude 讀圖）」，審片頁請作者對照原圖。
   沒記的數字對不到出處，會擋出片。
2. **來源行**寫 `"source": "來源：作者原文（圖N）"`（片尾卡會把幾張圖併成「作者原文（圖1、圖3）」）。
   原圖自己標了原始出處（例「資料：聯準會」），接在後面：`"來源：作者原文（圖2）；原始資料：聯準會"`。
3. **圖型照原圖的意思挑**：
   - 柱狀圖、表格的一列或一欄 → 柱狀；只挑旁白講到的那幾個，順序跟原圖一樣。
   - 走勢線 → 折線，只用圖上有標數值的點。**沒標數值的線不要估**：那條線是白名單公有數據（十年期、兩年期殖利率…）就用
     `publicData` 重抓（來源會寫 FRED，不是作者原文）；不是就只畫圖上有標的那幾點，或用文章文字裡的數字。
   - 一個關鍵數字 → 大數字。
   - 圓餅、占比 → 柱狀（%）。引擎沒有圓餅。
   - 好幾條線的圖 → 一個分鏡畫一條，或挑關鍵時點畫成並排的柱。
4. **照原圖的寫法**：類目名、年份、單位、系列名稱跟原圖一樣，數字的精度也一樣（原圖寫 4.5 就不要寫 4.50）——作者對照時才認得出來。
   標題照樣寫這張圖要說的結論（不是「圖2」）。
5. **一張圖講好幾句**：第一個分鏡畫圖，後面用接續分鏡換標註，一句一個重點。
6. 要引用原文某一句當證據：把那句的重點寫成標題或標註（數字照原文），不要把整段文字搬上畫面。

## 標註與數字

- **標註寫「意思」，不重複數值**：柱上已經寫 4.58%，標註寫「短天期較高」而不是「4.58%」。
  大數字和柱上的數字也不要重複；要強調某根柱的數字，用 `series[i].text` 把柱上的字改成說明。
- **差值一定帶單位**：百分比之差寫「個百分點」或「基點」（「高 0.62 個百分點」，不是「高 0.62」）。
- **畫面上每個數字都要有出處**：文章文字裡的數字、讀圖記下的數字（原文圖表）、公有數據，或宣告算式的推算（程式會擋：數字對帳）。
  數字寫成跟文章一樣的精度；文章寫「約」就在標籤或副標寫「約」。
- 文章是定性說法（「超過一半」）時，柱上寫 `"text": "＞50%"`，不要畫成剛好 50；需要的話 `badge` 寫「示意」。
- 作者自己的推估、換算，類目名寫清楚（「（作者推估）」），來源行分開「機構數字」和「作者推估」。
- 畫面上的年份寫阿拉伯數字（2023），不要寫「〇」（字型沒有，程式會擋）。

## 軸與圖型

- **柱一律從 0 起**（引擎自動）。**折線不從 0 起時圖上要寫明**：引擎會在副標後面自動加「縱軸未從 0 開始」，不要用 `axisNote` 把它拿掉。
- **下跌的數字不要用從 0 往上數的大數字**（`number` 會從 0 滾上去，跟「跌到」打架）：改用柱或標註。
- **機率、占比圖的縱軸寫死 `"yRange": [0, 100]`**：不寫的話，標註會在頭頂多留空間，縱軸會被推到 100% 以上。
  寫死之後標註擠的話，改用柱的顏色強調（`series[i].color`，寫了顏色的柱不會被標註淡掉），或另開一個分鏡。
- **縱軸被撐得太開**（線擠在圖的一小截、上面一大片空白）：先看標註是不是太長（改短），再不行就寫 `yRange` 把範圍寫死。
- **差異太小改畫差距**：幾個很接近的數（例如 102 和 105）畫成柱看起來一樣高。改畫「跟基準的差」（柱從 0 起），
  或用不從 0 起的折線並讓圖上寫明。
- 大數字（`number`）只放這張圖的指標；別的指標另開分鏡。一個分鏡只放一個大數字。
- 「警戒線」「門檻」：引擎畫不出水平參考線，標題和旁白不要說「線」，改說「門檻」「情境」。
- 折線的時間軸：`xTicks` 放在每月或每年的第一個點，名字不要重複；最後一點的名字不要只寫年份。月資料一年 12 點時最後兩個名字會擠，用 `xTicks` 挑。
- 副標要描述「所有」柱子（只有部分是公式算的，就不要整條副標寫公式）；柱子的順序跟標題提到的順序一致。
- 指數類數據（標普五百等）**只能用文章裡寫的數字或文章的圖上讀到的數字**，不能自己抓（版權）。

## 看靜態圖時的檢查清單

`preview` 會印每個分鏡完成狀態那張靜態圖的路徑（`build/16x9/stills/<片段>/` 裡還有每個畫面事件前一刻的圖）。逐張用 Read 看：

1. 這一張講的事跟那句旁白一樣嗎？旁白唸到的數字在畫面上嗎？
2. 標題是一句結論、兩行以內；字沒有被切掉、沒有疊在一起、沒有掉進底部字幕帶。
3. 標註寫意思、沒重複數值；差值有單位；標籤、引線沒有壓在線或格線上。
4. 柱從 0 起；折線不從 0 起的有寫明；機率圖沒有超過 100%。
5. 下跌的數字沒有用往上滾的大數字。
6. 跟前後分鏡比：圖型有變化；接續分鏡的版式和刻度跟上一張一樣。
7. 重畫文章的圖：跟原圖（`article/images/圖N.*`）並排看，數字、類目名、順序、單位都一樣；來源行寫了「作者原文（圖N）」。

有問題就改 shots.json 再 `preview`，只有改到的分鏡會重渲。
