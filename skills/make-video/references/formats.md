# 專案檔案的格式（你要寫的 JSON）

專案資料夾（`new` 印出來的「專案資料夾」）裡，你要寫的是：`narration.json`（旁白稿）、`shots.json`（分鏡設定），
文章的圖上有文字裡沒有的數字時再加 `article/figure_numbers.json`（讀圖記下的數字）。
都是 UTF-8 的 JSON。寫錯了 `preview` 會一次列出全部問題，每一條都說是哪個分鏡（或哪張圖）、哪個欄位，照著改就好。

能直接跑的完整例子（外掛自帶，不是任何人的文章）：`${CLAUDE_PLUGIN_ROOT}/src/article_to_video/sample_project/` 的
`narration.json` 和 `shots.json`（一個財經圖表分鏡＋一個接續分鏡）。

## narration.json（旁白稿）

```json
{"segments": {
  "s01": "兩年期殖利率，平均四點五八，比前一年高。十年期只有三點九六，曲線倒掛。",
  "s02": "短天期反而比長天期高，相差零點六二個百分點。這通常代表市場預期降息。"
}}
```

- 每一個鍵是一個**旁白段**，照寫的順序唸，段與段之間自動留一點空白。鍵用英數字（s01、s02…），改內容不要改鍵。
- 一段 25–60 字，規則見 `narration-rules.md`；寫完跑 `lint`。

## shots.json（分鏡設定）

```json
{"shots": [
  {"id": "SH01", "note": "給自己看的備註（不上畫面）",
   "start": {"segment": "s01"},
   "chart": {
     "data": {"title": "短天期殖利率反而比較高", "unit": "美國公債殖利率，2023 年平均，%",
              "source": "來源：FRED（DGS2、DGS10），年平均自算", "chart": "bar", "decimals": 2, "suffix": "%",
              "series": [{"label": "兩年期", "value": 4.58}, {"label": "十年期", "value": 3.96}],
              "highlight": {"index": 0, "text": "短天期較高"}},
     "cues": [
       {"at": 0, "kind": "title"},
       {"at": {"segment": "s01", "word": "殖利率"}, "kind": "bar", "data": {"index": 0}},
       {"at": {"segment": "s01", "word": "平均"}, "kind": "highlight"}]}},
  {"id": "SH02", "start": {"segment": "s01", "word": "十年期"}, "continues": true,
   "chart": {"data": {"highlight": {"index": 1, "text": "長天期較低"}},
             "cues": [{"at": {"segment": "s01", "word": "十年期"}, "kind": "bar", "data": {"index": 1}},
                      {"at": {"segment": "s01", "word": "只有"}, "kind": "highlight"}]}}
]}
```

（一句一個分鏡：SH01 唸到「殖利率」長兩年期那根柱、唸到「平均」（開始講它的數字）標「短天期較高」，唸到「四點五八」時標註已經長好；
SH02 接續它，唸到「十年期」切進來、十年期那根柱這時才長（SH01 裡沒有它），柱一長完、唸到「只有」標註就換到十年期。）

### 分鏡

| 欄位 | 說明 |
|---|---|
| `id` | 穩定的名字（SH01…，英數字）。審片頁的**分鏡編號**是它在清單裡的位置（1 起算），id 不會變 |
| `start` | 切入點（錨點）。第一個分鏡可以不寫（從 0 開始）；其他都要寫 |
| `chart` | 財經圖表（`data`＋`cues`，見下面）。每個分鏡都是財經圖表 |
| `continues` | `true`＝接續上一個分鏡：同一張圖（連標註）第一幀就跟上一個分鏡一模一樣、只換這一句的標註，切點看不出來（規則見下面「接續分鏡」） |
| `derived` | 推算出來的數字要宣告算式：`[{"value": "0.62", "formula": "4.58 - 3.96", "note": "兩年期減十年期"}]` |
| `note` | 備註，不上畫面 |

### 錨點（畫面事件對上旁白的位置）

`{"segment": "s02", "word": "曲線", "edge": "start", "offset": 0, "occurrence": 1}`

- `segment`：哪個旁白段。只寫這個＝那段開頭。
- `word`：那段裡的幾個字（一字不差）。同一段出現兩次以上要加 `occurrence`（第幾次），或寫長一點讓它只出現一次。
- `edge`：`"start"`（開始唸那個詞，畫面會提早 0.15 秒）或 `"end"`（唸完那個詞）。
- `offset`：再往後（正）或往前（負）幾秒。
- 改旁白時，被錨點用到的詞如果改掉了，錨點也要跟著改（`preview` 會說找不到哪個詞）。

### 財經圖表 `chart.data`

| 欄位 | 說明 |
|---|---|
| `title` | 一句結論（不是「XX 走勢」這種名稱）。橫式最多兩行 |
| `unit` | 副標：指標與單位，例「美國十年期公債殖利率，%」 |
| `source` | 來源行，例「來源：作者原文」「來源：作者原文（圖2）」（重畫文章的圖）「來源：FRED（DGS2）」。用 `publicData` 時自動寫，不要自己寫 |
| `chart` | 圖表版面：`"bar"`（柱，一律從 0 起）、`"line"`（折線；不從 0 起時副標自動加「縱軸未從 0 開始」）、`"number"`（大數字卡）、`"compare"`（兩數對比）。後兩種見下面「大數字卡、兩數對比」 |
| `series` | `[{"label": "兩年期", "value": 4.58}]`。柱寬跟著根數變：兩三根時柱子變寬（最寬 240 px）、整組靠在圖區中間，根數多時照原本；`text` 可蓋掉柱上的數字（例 `"＞50%"`），`color` 單根改色（例 `"#C0392B"`）。標註出現時，沒寫顏色的柱會淡成灰、只留被標的那根；**寫了 `color` 的柱一直是那個顏色**（不會被淡掉），所以顏色拿來對上片裡別處同一個量，不要拿來當「重點」 |
| `decimals`、`prefix`、`suffix` | 柱上、線頭數字的小數位數（預設 1）與前後綴 |
| `highlight` | 標註的預設值 `{"index": 0, "text": "意思", "sub": "第二行（選填）"}` |
| `xTicks` | 折線的 x 軸只在這些位置寫名字（索引清單），例每年第一個點。被標註的點不會另外加名字（換標註時 x 軸才不會跳）：標的時間點要讓人知道，就寫進標註的字（例「2024 年 9 月轉正」） |
| `yRange` | 縱軸範圍自己寫死：`[最小, 最大]`，例 `[-1, 2]`、機率或占比圖 `[0, 100]`（格線畫在範圍裡的整數刻度上，所以兩端寫整齊的數）。要包住所有數字、柱狀圖要包含 0，不然建置會擋。寫了就照寫的畫，不會為標註、大數字自動加高。通常不用寫：自動算的縱軸會先試著把標註放在線旁邊的空位，放不下才往上加一格刻度 |
| `badge` | 右下角小字，例「示意」（真實數據不要寫） |
| `axisNote` | 換掉「縱軸未從 0 開始」這句（很少需要） |
| `push` | 整串（第一個分鏡＋接續它的）鏡頭總共推近多少，0～0.2，寫在第一個分鏡；通常不用寫（自動算）。怎麼推看設定的圖表鏡頭（見下面「圖表鏡頭」）：快推（預設）＝平均分給整串每個新標註、標註出現時各推一下（每下至少 2%，分不到就少推幾下；寫不到 `0.02` 等於不推），`0`＝鏡頭不動；慢推＝整串等速慢慢推到這個量，`0`＝不推、會被自動檢查判成「沒在動」 |
| `publicData` | 公有數據：見下面 |

### 財經圖表的 cue（畫面事件）

| kind | 欄位 | 畫面 |
|---|---|---|
| `title` | `at` | 版式、標題、格線。通常 `"at": 0`：切進來時淡入；影片第一個分鏡的會在第一幀就到位（成片第一幀不是空白） |
| `bar`／`line` | `at`、柱可寫 `"data": {"index": 0}`（或清單）只長那幾根 | 圖型照 `chart`。柱：**帶 index 的柱在自己的時刻長出來**（一句長一根：每根寫一個；寫在接續分鏡＝那根柱到那一句才長，前面的分鏡不畫它）；**沒帶 index 的那一個**＝其他柱一起長的時刻；都沒寫＝版式之後自己長。同一根柱整串只長一次。折線：`line` 寫一個，在第一個分鏡 |
| `highlight` | `at`、`text`、`sub`、`data.index` | 標註（圓點＋引線＋字）。一個分鏡寫一個，要換標註就開接續分鏡 |
| `number` | `at`（數字落定的時刻）、`text`（說明）、`data.value`、`data.prefix`／`suffix`／`decimals` | 右上大數字，`at` 之前 0.9 秒從 0 往上滾、`at` 落定。一個分鏡只放一個；**下跌的數字不要用**。大數字卡、兩數對比的寫法不一樣（見下面） |
| `gap` | `at`（落定的時刻）、`text`（前面的字，預設「差」）、`data.suffix`（單位，必填） | 只用在兩數對比：兩個數字底下的差距（見下面） |

`at`：數字＝這個分鏡開始後幾秒；或錨點。資料類 cue（bar、line、highlight、number、gap）**一律用錨點**，對上旁白唸到的詞。

**數字（`number`、`gap`）的 `at` 寫在唸到那個數字的詞的開頭（`edge` 用預設的 `start`，不要寫 `end`）**：數字在 `at` 之前就開始滾或淡入，
唸到時已經落定。寫在唸完（`end`）的話，觀眾聽到數字時畫面上還是滾到一半的假數字。**落定之後至少要在畫面上停 1.5 秒**
（大數字卡到這個分鏡結束；兩數對比、圖上的大數字到這一串結束）：數字在句尾、下一句馬上切走的話，把下一個分鏡的切入點往後放，
或把旁白改成數字後面還有半句（「平均四點五八，比前一年高」）。停不到 1.5 秒 `preview` 會印一行「提醒：」點名哪個分鏡的哪個 cue（不擋，但審片一定會抓），照著改。
也不要提早到鋪陳的開頭：會滾的大數字（大數字卡、圖上的大數字）落定比旁白唸到它早 1 秒以上，觀眾看著停好的數字空等（審片會挑），`preview` 一樣會提醒。

**標註（`highlight`）的 `at` 寫在這句開始講它的那個詞**（被標的那一點的主詞、時間點，或帶出數字的那幾個字：「十年期」「二零二六年一月」
「相差零點六二」），`edge` 用預設的 `start`；**不要寫在數字唸完（`end`）或句尾**。換一次標註（舊的淡出、柱淡掉、新的字長出來）
要 0.5 秒才看得清楚，要在旁白唸到標註上的數字之前就長好——最晚錨在數字那個詞的開頭（唸數字的時候剛長好）。
錨在唸完或句尾的話，新的一句已經在講別的，畫面還是上一個標註（聽到「多了」、看到「少了」），計時實測第 1 輪 5 項必修全是這個。
標註從出現到換掉（下一個標註、切到別張圖）至少 1.5 秒。`preview` 會提醒「比旁白晚」「只停 X 秒」（標註上有數字才比得出晚，
沒有數字的標註要你自己照這條寫）；取捨見 storyboard-rules.md「標註跟著旁白」。

**寫了也沒作用的柱、線 cue `preview` 會擋**（點名哪個分鏡的哪個 cue）：接續分鏡裡沒帶 index 的 `bar`、`line`（沿用的圖第一幀就畫好了）、
同一根柱長兩次、標到不存在的柱（一個分鏡寫兩個沒帶 index 的 `bar`：只有最早的那個有作用，會印「提醒：」）。柱的錨點指到下一個分鏡唸的詞會被擋（「在 SH01 結束之後」）：那根柱要在下一句才長，
就把那個 bar cue 搬到下一個分鏡（接續分鏡）裡。

### 接續分鏡（財經圖表）

接續分鏡沿用上一個分鏡的整張圖（data 只能改 `highlight`）：柱、線、大數字、**上一個分鏡的標註和淡掉的柱**，
第一幀都跟上一個分鏡的最後一幀一模一樣（鏡頭也接著：慢推接著推、快推從上一下停住的地方接著），切點看不出來。只有這一句要換的東西會動：

- 長一根柱：寫自己的 `{"at": 錨點, "kind": "bar", "data": {"index": 2}}`。那根柱到這一句唸到那個詞才長出來；
  **前面的分鏡都不畫它**（建置照整串一起算哪些柱在後面才長），所以切點不跳。「一句長一根柱」和「一句換一個標註」可以並存：
  一句一個接續分鏡，各寫各的 `bar` 或 `highlight`（上面例子的 SH02 兩個都寫）。一定要帶 `index`；沒帶 index 的 `bar`、`line` 寫在這裡沒有作用（會被擋）。
- 換標註：寫自己的 `{"at": 錨點, "kind": "highlight"}`（字寫在 `data.highlight` 或 cue 的 `text`）。唸到那個詞之前，
  上一個分鏡的標註照舊留著；唸到時才換——同一點只換字（圓點不動、舊字淡出、新字長出來）；換到別根柱或折線別一點時，
  舊的淡出、新的圓點彈出來，淡掉的柱跟著換（兩次都淡掉的柱一直淡著，不會閃回原色）。錨點寫在這一句開始講它的詞（見上面「標註」）。
- **同一點只加或改第二行（`sub`）、第一行不變，看起來會閃一下**：引擎一樣把整個標註淡出再長出來，第一行的字消失一下又回來
  （計時實測審片判該修，`preview` 會提醒）。要補充就換一句新的第一行（「2023 年」→「2023 年：4.58%」），或上一個標註一開始就兩行一起寫。
- 換大數字：圖上的大數字（`number`）寫在接續分鏡就換成新的那一個。
- 切點放在這一句要出現的東西那個詞最順：`start` 跟那個 cue 寫同一個錨點（上面例子的 SH02：唸到「十年期」切進來、那根柱跟著長）。
- 什麼都不寫＝畫面不變（只是把分鏡切開，例如想在審片頁分開指認）。
- 換到折線最後一點時，線尾的數值會淡出讓位；換離最後一點時再淡回來。
- 兩數對比也能接續（換強調、補差距、讓第二個數字這一句才落定）；大數字卡不能（見上面「大數字卡、兩數對比」）。
  數字、差距的動畫在落定之前 0.5～0.9 秒就開始：接續分鏡從唸到那個數字的詞切進來、數字又錨在同一個詞，動畫的前半段落在切點之前，
  切點會跳出半個數字。切點提早到引出它的詞（例「相差」），或數字的錨點加 `"offset": 0.5`。

一串（第一個分鏡＋後面接續它的）的版面由建置一次算好：照整串**所有**分鏡的標註（標在正數柱上面、負數柱下面、
折線哪一點、幾行字）和大數字留空間，所以整串的刻度、圖區從頭到尾一樣，切點不跳。第一個分鏡可以沒有標註、
後面的分鏡可以多一行 `sub`、大數字可以只在後面的分鏡出現（前面的分鏡會先空著那一條）。

### 大數字卡、兩數對比（`"chart": "number"`／`"compare"`）

版式跟柱狀圖、折線一樣（色條、小旗、標題、副標、來源行），中間不畫圖，改放大數字。什麼時候用哪一種見 storyboard-rules.md「圖表版面要有變化」。

```json
{"shots": [
  {"id": "SH01", "start": {"segment": "s01"},
   "chart": {"data": {"title": "短天期利率反而比較高", "unit": "美國兩年期公債殖利率",
                      "source": "來源：FRED（DGS2），年平均自算", "chart": "number"},
             "cues": [{"at": 0, "kind": "title"},
                      {"at": {"segment": "s01", "word": "四點五八"}, "kind": "number",
                       "text": "2023 年平均", "data": {"value": 4.58, "decimals": 2, "suffix": "%"}}]}},
  {"id": "SH02", "start": {"segment": "s01", "word": "十年期"},
   "chart": {"data": {"title": "兩年期比十年期高", "unit": "美國公債殖利率，2023 年平均，%",
                      "source": "來源：FRED（DGS2、DGS10），年平均自算", "chart": "compare", "decimals": 2, "suffix": "%",
                      "series": [{"label": "兩年期", "value": 4.58}, {"label": "十年期", "value": 3.96}],
                      "highlight": {"index": 0}},
             "cues": [{"at": 0, "kind": "title"},
                      {"at": {"segment": "s01", "word": "十年期"}, "kind": "number", "data": {"index": 0}},
                      {"at": {"segment": "s01", "word": "三點九六"}, "kind": "number", "data": {"index": 1}},
                      {"at": {"segment": "s01", "word": "倒掛"}, "kind": "highlight"}]}},
  {"id": "SH03", "start": {"segment": "s02", "word": "相差"}, "continues": true,
   "chart": {"data": {},
             "cues": [{"at": {"segment": "s02", "word": "零點六二個百分點"}, "kind": "gap",
                       "text": "高", "data": {"suffix": " 個百分點"}}]}}
]}
```

（旁白用上面 narration.json 的例子：SH01 唸到「四點五八」時數字已經滾完落定，後面還有半句「比前一年高」，數字停得夠久才切走；
SH02 切到十年期，兩年期的數字先放上來、唸到「三點九六」十年期落定、唸到「倒掛」強調兩年期；SH03 接續它，
唸到「零點六二個百分點」標出差距「高 0.62 個百分點」。）

| 版面 | `chart.data` | cue |
|---|---|---|
| 大數字卡 `number` | `title`、`unit`（副標：這是什麼指標）、`source`、`badge`、`colors`、`push`。沒有 `series`、軸 | `title`；**剛好一個** `number`：`data.value`、`data.suffix`（單位，例 `" 天"`）、`prefix`、`decimals`，`text`＝說明（必填，一行，寫在數字底下） |
| 兩數對比 `compare` | 同上，再加 `series`（**剛好兩個**：`label`＝那個數字的說明、`value`）、`decimals`、`prefix`、`suffix`、`highlight`（只寫 `index`） | `title`；`number` 寫 `data.index`（0、1，或 `[0, 1]`）＝這一刻落定的是哪一個，**兩個都要有**；`highlight`＝強調其中一個（不寫字）；`gap`＝差距 |

- **大數字卡**：數字很大，靠左對齊標題、放在中間那塊偏上；單位（`suffix`）字小一點。`at` 之前 0.9 秒從 0 滾上去，`at` 那一刻落定（跟右上角的大數字一樣），說明跟著淡入。
  畫面上只有這個數字，所以時間要抓好（計時實測：寫在唸完、切點又緊跟在後，數字只停 0.4 秒、觀眾看到的是滾到一半的 781，審片判必修）：
  - `at` 寫在引出數字的那個詞（「十年期減兩年期的利差，連續倒掛七百八十二天」寫 `{"segment": "s01", "word": "連續倒掛"}`），
    或數字那個詞的開頭（`edge: start`）：數字唸到時剛好落定。**不要提早到鋪陳的開頭**（「利差」）：計時實測數字在唸到之前
    約 2 秒就數完、卡片空等，審片會挑；落定比唸到早 1 秒以上、或晚了（寫在唸完 `end`），`preview` 都會提醒。
  - 落定後至少停 1.5 秒才切到下一個分鏡（停不到 `preview` 會提醒）；數字在句尾的話，下一個分鏡從下一句後面一點的詞切入，或旁白在數字後面補半句。
  **下跌的數字不要用**（從 0 往上數會跟「跌到」打架）：講「從多少到多少」用兩數對比。
- **兩數對比**：橫式左右並排、直式上下疊，兩個數字同一個字級。每個數字在它的 `at` 淡入、往上浮一點落定（不滾：比的是確切的數字，
  滾動會經過一串假的數，也會把「從 4.58 降到 3.81」演成往上數）。說明寫在數字底下（`series[i].label`，一行為原則，最多兩行）。
  - 強調（`highlight`，`index` 寫在 cue 的 `data.index` 或 `data.highlight.index`）：被強調的數字換成品牌色、另一個連說明淡成灰（還讀得到）。不寫字：要說的意思寫進標題或說明。
  - 差距（`gap`）：兩個數字底下一條細線，再一行「差 0.62 個百分點」。數字是程式照**畫面上**的兩個數字算的（後一個減前一個，取絕對值，小數位數跟兩個數字一樣），
    不用自己寫；`text` 是前面的字（「差」「高」「拉開」「少了」，預設「差」），`data.suffix` 是單位，**一定要寫**，不能是 `%`（百分比相減是「個百分點」）。
- **接續**：大數字卡**不能**被接續（只有一個數字，沒東西可換；下一句另開分鏡）。兩數對比可以：接續分鏡沿用兩個數字和強調，
  可以換強調、補上差距，或讓第二個數字等到這一句才落定（`number` 寫在接續分鏡裡）。整串只要有差距，第一個分鏡就先留好它的位置，切點時數字不會跳。
- **鏡頭**：快推時，兩數對比的強調跟標註一樣推一下（往被強調的數字推）；數字落定、差距、大數字卡都不推（數字滾動、淡入本身就是這一拍的動作）。慢推照舊整串慢慢推。
- **數字對帳**：大數字卡的數字和說明、兩數對比的兩個數字和說明都要對得到出處（文章、讀圖記下的數字、宣告的推算）。
  差距：文章裡寫了這個差就是原文；沒寫的話，兩個數字都有出處就自動算推算（不用寫 `derived`）。
- 寫錯了（大數字卡沒說明、兩數對比三個數字、差距沒單位…）`preview` 會點名哪個分鏡哪個欄位。

### 圖表鏡頭（設定 `camera`）

整支片的財經圖表用同一種鏡頭，存在設定快照裡（不是寫在分鏡設定）：

| 設定 | 畫面 |
|---|---|
| `slow`（慢推） | 整串一直等速慢慢推近：每秒 0.4%（整串長的話更慢，總共最多 6%），從頭推到尾，切點接著推 |
| `snap`（快推，**目前的預設**） | 畫面平常停住；**新標註出現的那一刻快推一下**（0.45 秒，先快後慢：第一幀只走兩成，不會頓一下），然後停住。推近時被標註的那一點在畫面上不動、其他東西往外推開，眼睛不用找。整串預設總共推近 6%（跟慢推整串最多推的一樣），平均分給每個標註，**每下至少 2%、最多 4%**：一串一個標註推 4%、兩個各 3%、三個各 2%；再多就分不到 2%，只推三下——先推每個分鏡的第一個新標註（換分鏡＝換重點），剩下的照時間順序，推完就停，其餘的標註只換字、鏡頭不動（一推 1% 看起來像畫面抽一下）。被標註的點在畫面上不動、內容又不能出範圍，所以點靠畫面邊時推得比較少；少到不到 1.5% 那一下就不推（直式、點很多的折線標最後一點，常常第一下之後就不推了）；前一下少推或沒推，下一下不會補。標題、來源行、刻度值、x 軸名字不會被切掉、貼到畫面邊或推進字幕帶。沿用上一個分鏡的標註、跟上一個一模一樣的標註、大數字都不推 |

- 改這支片：`settings set --project "<專案>" --camera 慢推`（或 `快推`）；以後的片都要就拿掉 `--project`。改了整支片的圖表片段會重渲。
- 快推時「一句旁白一個畫面事件」更要緊：畫面只在有新東西時動，停住超過約 5 秒會被提醒「停太久」。
- 舊片（設定快照是有這個設定之前做的，快照裡沒有 `camera`）一律補成慢推：預設改成快推之後重建也照舊、不換鏡頭。要換成快推就 `settings set --project "<專案>" --camera 快推`。

### 公有數據（自動抓、自動寫出處）

```json
"data": {"title": "十年期通膨預期，大致持平", "unit": "美國十年期通膨預期，%", "chart": "line", "decimals": 2, "suffix": "%",
         "publicData": {"series": "DGS10-DFII10", "from": "2025-01-01", "to": "2025-12-31", "every": "month"}}
```

- `series`：只能用 `DGS10`（十年期）、`DGS2`（兩年期）、`DFII10`（實質殖利率）、`THREEFYTP10`（期限溢價），或兩個相減（`"DGS10-DFII10"`＝通膨預期、`"DGS10-DGS2"`＝利差）。
  標普五百等指數、`T10YIE` 一律不抓（版權）：只能用文章裡寫的數字，或文章的圖上讀到的數字（重畫，見下一節）。
- `every`：`day`／`month`／`quarter`／`year`（期間平均）。`from`、`to` 都要寫（YYYY-MM-DD）。
- 寫了 `publicData` 就不要寫 `series`、`source`。第一次抓要有網路；抓過的存在專案裡，之後重建不用網路。

## 讀圖記下的數字（article/figure_numbers.json）

文章的圖上有數字、文字裡沒有，而畫面要用到時（重畫文章的圖，見 storyboard-rules.md），Read 那張圖之後把讀到的數字寫在這裡：

```json
{"figures": {
  "圖1": [{"value": "4.58", "label": "兩年期殖利率，2023 年平均"},
          {"value": "3.96", "label": "十年期殖利率，2023 年平均"},
          {"value": "2020", "label": "橫軸年份（第二根柱的類目名）"}]
}}
```

- 鍵是圖號，照 `article/article.json` 的圖（圖1、圖2…）。
- `value`：圖上那一個數字，**照圖上的寫法寫成字串**（圖上 4.50 就寫 `"4.50"`，寫成數字 4.50 會變 4.5）；單位（%、兆）不用寫。
- `label`（必填）：這個數字在圖上是什麼——哪一列／哪一欄、哪一年、哪個系列。審片頁會列給作者對照原圖。
- 只記圖上清楚寫出來的數字，不要從線的高度估。
- 軸上、類目上的數字也算：重畫時照抄到畫面的橫軸年份、月份、類目名裡的數字，文字裡沒有就要記（數字對帳會查類目名和單位行）。
- 數字對帳把畫面上對得到這些數字的標成「原文圖表（圖N，Claude 讀圖）」；推算（`derived`）的算式也可以用它們。
- 重跑文章擷取（`extract`）會拿掉這個檔：圖換了要重讀。

## settings.json（設定快照，通常不用動）

第一次預覽時會從作者的使用者設定複製進來（頻道名、聲音、配樂、品牌色、預設比例、圖表鏡頭）。只改這一支片時用
`settings set --project "<專案>" --voice 曉雨 …`，不要直接手改。`tail`＝片尾卡秒數（預設 5）。
語速 `rate` 預設 +15%（作者說「講快一點／慢一點」就 `settings set --project "<專案>" --rate +20%`，以後的片都要就拿掉 `--project`；
改了會整支重新配音）。段與段之間的留白 `gap` 預設 0.25 秒；每段頭尾配音自帶的空白會自動修掉，不用管。
